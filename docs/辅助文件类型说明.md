# 辅助文件类型说明

本文档列出了 LaTeX 编译过程中常见的辅助文件后缀及其用途，供参考。

## 文件列表

| 后缀 | 功能和作用 | 说明 |
| --- | --- | --- |
| `.pdf` | 生成的 PDF 文档 | Portable Document Format，便携式文档格式 |
| `.synctex.gz` | 同步 TeX 源文件和 PDF，便于正向/反向搜索 | SyncTeX 技术，`.gz` 为压缩格式 |
| `.log` | 编译日志文件，记录编译过程详细信息 | Log file |
| `.blg` | BibTeX 日志文件 | BibTeX Log file |
| `.ilg` | MakeIndex 日志文件 | MakeIndex Log file |
| `.aux` | 辅助文件，存储交叉引用、标签等信息 | Auxiliary file |
| `.bbl` | BibTeX 生成的参考文献列表 | BibTeX Bibliography file |
| `.xml` | XML 格式数据，常用于 BibTeX 输入输出 | eXtensible Markup Language |
| `.toc` | 目录文件，存储章节结构 | Table of Contents |
| `.lof` | 图目录文件 | List of Figures |
| `.lot` | 表目录文件 | List of Tables |
| `.out` | 输出文件，存储临时输出信息 | Output file |
| `.bcf` | Biber 配置文件 | Biber Configuration File |
| `.idx` | 原始索引文件 | Index file |
| `.ind` | MakeIndex 生成的格式化索引 | Index file (generated by MakeIndex) |
| `.nlo` | nomencl 生成的术语列表 | nomencl List of Terms |
| `.nls` | nomencl 生成的排序后术语 | nomencl List of Terms Sorted |
| `.ist` | MakeIndex 样式文件，定义索引格式 | Index Style file |
| `.glo` | glossary 术语原始文件 | Glossary file |
| `.gls` | MakeIndex 生成的格式化术语表 | Glossary file (generated by MakeIndex) |
| `.bak` | 备份文件 | Backup file |
| `.spl` | 拼写检查文件 | Spell Check file |
| `.ent-x` | XML 实体扩展文件 | Entity eXtension file |
| `.tmp` | 临时文件 | Temporary file |
| `.ltx` | LaTeX 源文件 | LaTeX source file |
| `.los` | 符号目录 | List of Symbols |
| `.lol` | 代码行目录 | List of Lines |
| `.loc` | 位置文件 | Location file |
| `.listing` | 代码列表文件 | Listing file |
| `.gz` | Gzip 压缩文件 | Gzip compressed file |
| `.userbak` | 用户备份文件 | User Backup file |
| `.nav` | Beamer 导航文件 | Beamer Navigation file |
| `.snm` | Beamer 会话文件 | Beamer Session file |
| `.vrb` | Beamer 抄录文件 | Beamer Verbatim file |
| `.fls` | LaTeX 外部引用记录文件 | LaTeX File List file |
| `.xdv` | XeLaTeX 生成的 DVI 文件 | XeLaTeX DVI file |
| `.fdb_latexmk` | LaTeXmk 数据库文件 | LaTeXmk File Database file |
| `.run.xml` | Biber 运行时配置文件 | Biber Run XML file |
